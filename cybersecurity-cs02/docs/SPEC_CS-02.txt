1. Project Overview
Web applications are a major component of modern information systems. They commonly handle authentication, user information, business processes,
databases, and other sensitive operations.

A web application may be exposed to security risks because of insecure application logic, improper access control, weak authentication, insecure configuration,
inadequate input validation, or vulnerable software components.

This project requires the student group to build or deploy an intentionally vulnerable web application in an isolated laboratory environment and perform a
structured security assessment.
The recommended application is OWASP Juice Shop. Alternatives such as DVWA or WebGoat may be used with instructor approval.

The project will focus on identifying, documenting, analyzing, and where practical remediating web-application security weaknesses.

The project must follow this lifecycle:

Application Discovery → Mapping → Security Testing → Vulnerability Identification → Controlled Validation → Risk Analysis → Remediation →
Re-Testing → Reporting

This is an authorized educational security assessment. No public or third-party web application may be tested.


2. Problem Statement
Organizations increasingly depend on web applications to provide services to users.

Security weaknesses in web applications may allow unauthorized users to access information, bypass security controls, manipulate application behavior, or
perform actions beyond their intended privileges.

A structured application-security assessment can identify such weaknesses before they are introduced into a production environment.

This project aims to demonstrate how a security professional can assess an intentionally vulnerable web application, document security weaknesses, analyze
their impact, and recommend appropriate security controls.
