CS-02 — Web Application Security Assessment

OWASP methodology assessment of OWASP Juice Shop 20.2.0. This is the public, documentation-only demonstration build. The vulnerable application itself is not published and runs only inside an isolated local laboratory.

What a remediation had to prove

Each fix is only accepted when the attack result changes and legitimate use still works — otherwise the "fix" would just be a broken application. Every re-test pairs an attack probe with a functional control.
